# キックオフ記録 — PWA版

サッカーの試合時間と得点を記録するアプリのインストール可能版（PWA）です。
無料の静的ホスティングに置くと、スマホのホーム画面から**全画面のアプリ**として起動でき、
一度開いた後は**オフライン**でも動きます。Claudeの契約やアカウントは不要で、Claudeとは独立して動作します。

## 含まれるファイル

- `index.html` … アプリ本体（これ1つで動きます）
- `manifest.webmanifest` … アプリ名・アイコン・全画面表示などの設定
- `sw.js` … オフライン対応（Service Worker）
- `icon-*.png` … ホーム画面・起動時のアイコン一式

すべて同じフォルダに置いたまま公開してください（ファイル名は変えないでください）。

## 公開方法（いずれか1つ）

**重要**: PWAは `https://`（またはローカルの `localhost`）でないとインストール・オフラインが有効になりません。
下記のサービスはすべて自動でHTTPSになります。

### A. Netlify Drop（最も簡単・ドラッグ&ドロップ）
1. https://app.netlify.com/drop を開く
2. この**フォルダごと**枠内にドラッグ&ドロップ
3. 発行されたURLをスマホで開く → 下記「ホーム画面に追加」

### B. GitHub Pages
1. GitHubで新しいリポジトリを作成し、この中身をすべてアップロード
2. Settings → Pages → Branch を `main` / `/root` にして保存
3. 数分後に表示される `https://<ユーザー名>.github.io/<リポジトリ名>/` を開く

### C. Vercel / Cloudflare Pages
- どちらも無料。フォルダをアップロード（または上記リポジトリを連携）するだけで公開できます。

## ホーム画面に追加してアプリ化

- **iPhone (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー（⋮）→ 「アプリをインストール」または「ホーム画面に追加」

追加後はアイコンから全画面で起動し、電波がなくても使えます。

## 動作メモ

- 記録データは端末のブラウザ内（localStorage）に保存されます。端末・ブラウザをまたいでの同期はしません。
- アイコン・見た目を変えたい場合は、`manifest.webmanifest` と `icon-*.png` を差し替えてください。
- アプリを更新したいときは `index.html` などを差し替えて再アップロードすればOKです
  （反映されない場合は、ブラウザでページを再読み込みしてください）。
